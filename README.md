#  Hexpar AI

> An advanced, ultra-responsive, futuristic neural conversational AI interface. Inspired by sci-fi HUDs and built with cutting-edge front-end and back-end integration.

---

## 🌟 Key Features

* 🎙️ **Continuous Speech-to-Text (STT)** — Interactive real-time voice command listening loop.
* 🔊 **Neural Text-to-Speech (TTS)** — Immediate, high-fidelity sentence-by-sentence audio responses.
* 💻 **Sci-Fi Terminal HUD Dashboard** — Aggressive geometric styling, live telemetry, and neural visualizers.
* 🧠 **Groq-Powered Intelligence** — Ultra low-latency conversational reasoning.
* 🎨 **Premium Aesthetics** — Custom HSL tailored colors, dark mode, smooth gradients, and interactive micro-animations.

## 🚀 Getting Started

### Prerequisites

* [Node.js](https://nodejs.org/) (v18+)
* [Git](https://git-scm.com/)

### Installation & Launch

1. Install dependencies for the root, front-end, and back-end directories:
   ```bash
   # Root dependencies
   npm install

   # Front-end dependencies
   cd front-end && npm install

   # Back-end dependencies
   cd ../back-end && npm install
   ```

2. Launch the entire platform concurrently:
   ```bash
   # From root folder
   npm start
   ```
